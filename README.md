# Conversor de Moedas em Python (Tkinter)

Este é um aplicativo simples feito em **Python + Tkinter**, que permite converter valores entre diferentes moedas de forma rápida.

### 🪙 Moedas suportadas
- BRL — Real Brasileiro  
- USD — Dólar Americano  
- EUR — Euro  
- ARS — Peso Argentino  

### 💻 Como funciona
1. O usuário digita o valor.
2. Informa a moeda de origem (ex: `BRL`).
3. Informa a moeda de destino (ex: `USD`).
4. O programa mostra o resultado na tela.
5. Há também um botão para encerrar a aplicação.

### 📦 Como executar
```bash
python conversor_moedas.py
```

### 🛠 Tecnologias usadas
- Python 3
- Tkinter
